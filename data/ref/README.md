# data/ref

Derived reference data. Runtime never fetches; the datastore reads these files offline (FileStore) or the `geo.*` / `ref.*` tables seeded from them (PgStore).

- `movements2015/{IATA}.csv.gz`: BTS 2015 arrivals and departures (wheels on/off, taxi in/out) for the top 30 airports by 2015 arrivals plus the benchmark airports (32). Generated by `python3 scripts/fetch_bts.py --movements2015`, seeded to Postgres with `python3 scripts/db_seed.py movements2015`. **Not in git** (about 94 MB, gitignored and dockerignored). When absent (offline checkout, or an airport outside the set) `movements_day` returns `None` and the backend uses generic ground traffic, badged partial (spec 6.9).
- `procedures/`: FAA CIFP 2611 (not for navigation). `surface/`: OSM surface graphs (© OpenStreetMap contributors, ODbL).
